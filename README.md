## 入れ替え手順
1. スプレッドシート（ID: 1b_bkfKRvPBaiOtrgMD72XSfCZZ-MApNFpEmM5lLdI20）の拡張機能 → Apps Script を開く
2. `コード.gs` の中身をすべて置き換える
3. `index` の中身をすべて置き換える
4. 関数 `setupSheets` を1回実行する（または、スプレッドシートを開き直して「運営指導対策 → 初期シート作成」を押す）
   - 足りないシート（事業所基本情報・運営指導履歴・書類管理・インシデント・人事登録・法務相談・健診取込ログ）だけを作ります。今あるシートには触りません
   - サンプル行が入るので、実データに置き換えてください
5. （健診OCRを使う場合）エディタ左の「サービス」→ Drive API を追加
6. （法務相談の通知を使う場合）プロジェクトの設定 → スクリプト プロパティに `LEGAL_MAIL` を追加
7. デプロイ → デプロイを管理 → 編集 → 新バージョンでデプロイ

シートがまだないデータは画面で「サンプル」と表示されます。右上のバッジにカーソルを当てると、どのデータがシート連動かが分かります。
